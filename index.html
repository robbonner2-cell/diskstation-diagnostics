How this snapshot was measured

Verified

  • Data read once, live, from each box's SYNO.Storage.CGI.Storage, SYNO.Core.System and SYNO.Backup.Task endpoints with a session login; no writes, no package changes.
  • Each headline number on this page re-derived from the same pull: 13/13 self-checks passed. A pull that fails any of them is never published.
  • Uptime is DSM up_time (H:MM:SS), not days.

Not verified

  • Drive-level SMART verdicts are DSM's smart_status field only — no on-box smartctl was run, so the failing disk is a strong lead, not a confirmed verdict.
  • Backup state is DSM's own state field; the API exposes the state, not the last error.
  • Backup coverage is scoped to Hyper Backup tasks; Snapshot Replication, Cloud Sync and rsync were not queried.
  • LAN addresses, credentials and hostnames are withheld from this page.
